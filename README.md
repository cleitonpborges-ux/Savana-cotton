# Viterra Dashboard Algodão 2026

Dashboard de controle de carregamento de algodão — Viterra.

## 📁 Arquivos

| Arquivo | Descrição |
|---|---|
| `index.html` | Dashboard principal |
| `manifest.json` | Configuração do PWA (ícone, tela cheia, nome) |
| `sw.js` | Service Worker (permite instalar o app) |
| `icon.png` | Ícone do aplicativo |

## 🚀 Como publicar no GitHub Pages

1. Crie um repositório **público** no GitHub
2. Faça upload de todos os 4 arquivos
3. Vá em **Settings → Pages**
4. Em **Branch**, selecione `main` → `/root` → **Save**
5. Aguarde ~1 minuto e acesse o link gerado

## 📱 Instalar como app

Após abrir o link no **Chrome** ou **Edge**:
- Um botão de instalar aparece automaticamente na barra de endereço
- O app abre em **tela cheia** sem barra do navegador
- Funciona também no celular (Android)
